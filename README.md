# MySQL и Node.js Приложение

Полноценное REST API приложение на Node.js с подключением к реляционной базе данных MySQL. Включает архитектуру MVC, пул соединений и обработку ошибок.

## 📋 Содержание

- [Требования](#требования)
- [Установка](#установка)

## 🔧 Требования

| Компонент | Версия |
|-----------|--------|
| Node.js | 14.x или выше |
| MySQL | 8.x или выше |
| npm | 6.x или выше |
| yarn (опционально) | 1.22.x или выше |
